## Опис роботи

У межах лабораторної роботи розв'язано дві прикладні задачі із використанням стандартної структури даних `collections.deque` зі стандартної бібліотеки Python у ролі стеку (LIFO) та черги (FIFO):
1. **`isBalanced(line)` (Стек / LIFO)** — перевіряє правильність розстановки круглих `()`, квадратних `[]` та фігурних `{}` дужок у рядку з ігноруванням усіх інших символів та перевіркою стеку на порожність перед вилученням елемента.
2. **`processQueue(requests)` (Черга / FIFO)** — моделює послідовну обробку заявок у порядку їх надходження з підрахунком часу початку, завершення, загального часу роботи та середнього часу очікування в черзі.

## Як запустити проєкт

1. Переконайтеся, що на комп'ютері встановлено **Python 3**:
   ```bash
   python --version
   ```

2. Перейдіть у папку лабораторної роботи `lab07`:
   ```bash
   cd lab07
   ```

3. Запустіть скрипт у терміналі:
   ```bash
   python lab07.py
   ```
   *(На Linux або macOS може знадобитися команда `python3 lab07.py`)*
